# PelagicLens
PelagicLens is a platform that transforms Copernicus Marine oceanographic information into intelligence for interpreting fisheries indicators.

### Architecture Workflow
The project operates on a 5-layer pipeline:
1. **OCEAN**: Ingestion of physical/biogeochemical data from Copernicus Marine.
2. **FISH**: Spatiotemporal models of pelagic species distribution.
3. **OBSERVATION**: Overlap calculation using fleet footprints and simulated vessel telemetry.
4. **SIGNAL**: Evaluation of index reliability and catchability shift risks.
5. **DECISION**: Actionable alerts and context for fisheries managers.

*Built for the Copernicus Marine Service Hackathon.*
